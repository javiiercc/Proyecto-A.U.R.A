# A.U.R.A.

Aplicación Universitaria de Rutas Asistidas

A.U.R.A. es una plataforma web diseñada para facilitar la orientación dentro del campus San Joaquin de la Universidad Técnica Federico Santa María mediante rutas inteligentes e imágenes panorámicas de 360°.

## Problema

Los ¨mechones¨ suelen tener dificultades para encontrar salas, laboratorios y otros espacios dentro del campus, generando pérdidas de tiempo, retrasos y desorientación.

## Solución

La plataforma permite seleccionar un punto de origen y un destino para generar automáticamente una ruta óptima. Además, utiliza imágenes 360° para guiar visualmente al usuario durante el recorrido.

## Funcionamiento

1. El usuario selecciona origen y destino.
2. El sistema calcula la ruta más corta utilizando el algoritmo de Dijkstra.
3. El servidor devuelve la secuencia de pasos e imágenes asociadas.
4. El usuario navega mediante una interfaz interactiva con indicaciones paso a paso.
